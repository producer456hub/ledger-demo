# LEDGER - public demo

**Live: https://producer456hub.github.io/ledger-demo/**

LEDGER is a personal spending instrument: Apple Card statement exports in, a single page out - pace for the
month, recurring bills, habits, a "cut spending" plan with live arithmetic, flags worth a look, refunds owed,
budgets that watch without nagging, when and where purchases happen, and a plain-words Ask box.

This demo is the **real engine on invented data**. The unmodified server (`engine/server.py`,
`ledger_core.py`, `motive.py`) runs inside your browser under [Pyodide](https://pyodide.org); the page's own
API calls are handed to it through a fake socket. The database is a year of made-up purchases in a made-up
town (`engine/ledger.db`, generated by the project's fixture), the clock is frozen at the day of the build,
and nothing you do leaves the tab. Reload and it is back to the start.

What is missing, on purpose:

- **No language model.** The live instance hands Ask questions to a local model that picks a calculator and
  writes the words. Here the question goes straight to the calculators.
- **No fleet.** No phone taps, no watch check-ins, no drive log, no statement imports - the parts of LEDGER
  that read from the owner's other machines are quiet.

Everything in this repository is generated by `demo/build_demo.py` in the (private) ledger-server repo.
Nothing here is a real transaction.
